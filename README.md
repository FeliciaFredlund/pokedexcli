## About This Project
Pokedex CLI is a guided project at [Boot.dev](https://www.boot.dev/) which is an educational site that trains people to be backend coders. While this project has some guidance and advice for each step, it is up to the student to figure out how to code the project.

## Learning Goals
* Network calls to external API
* Working with JSON
* Implementing caching
